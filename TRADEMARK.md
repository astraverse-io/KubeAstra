# KubeAstra Trademark Policy

The name **"KubeAstra"**, the KubeAstra logo, and the KubeAstra star glyph
(the "Marks") are trademarks of the KubeAstra project maintainers
(Astraverse).

KubeAstra's source code is licensed under the Apache License 2.0. That
license grants broad rights to use, modify, and redistribute the **code** —
but, per Section 6 of the Apache License, it does **not** grant any rights to
the Marks. This document describes how the Marks may and may not be used.

## Why we have this policy

When someone downloads something called "KubeAstra," they should get the
software published by this project — built, signed, and tested by its
maintainers. This matters more than usual here: KubeAstra reads kubeconfig
files and executes commands against Kubernetes clusters. If a modified build
carried our name, users could not tell whose code they were trusting with
their cluster credentials.

## Allowed without permission

You may, without asking us:

- Use the name "KubeAstra" to **refer to this project truthfully** — in
  articles, blog posts, talks, tutorials, videos, benchmarks, comparisons,
  and package-manager descriptions.
- State that your software or service **works with, integrates with, or is
  compatible with** KubeAstra (e.g., "MyTool — a plugin for KubeAstra"), as
  long as the naming doesn't imply we made or endorsed it.
- Redistribute **unmodified official releases** (binaries or source) under
  the KubeAstra name — for example, packaging an official release for
  Homebrew, winget, AUR, or a corporate mirror — provided you don't alter
  the software and you make clear where it came from.
- Fork the repository on a code-hosting platform, keeping the repository
  name, for development and contribution purposes (this is how GitHub
  forks work and is expected).

## Requires permission

Ask us first (open a GitHub issue or email the maintainers) before:

- Distributing **modified versions** of KubeAstra under the KubeAstra name
  or logo. If you ship a modified build, rename it (e.g., "AcmeOps K8s
  Assistant, based on KubeAstra") and remove our logos.
- Using the Marks in a **product name, service name, company name, domain
  name, or app-store listing** (e.g., "KubeAstra Pro", "kubeastra-cloud.com",
  a "KubeAstra" entry in an app store not published by us).
- Offering KubeAstra as a **hosted or managed service** marketed under the
  KubeAstra name.
- Using the Marks on **merchandise** for sale.
- Using the Marks in **advertising or sponsorship** in a way that implies
  endorsement by or affiliation with the KubeAstra project.

## Never allowed

- Using the Marks in a way that is misleading about the source of software —
  in particular, publishing modified builds, installers, or packages that
  present themselves as official KubeAstra releases.
- Registering trademarks, domains, or social-media handles that are
  confusingly similar to the Marks in order to trade on the project's
  identity.

## Logo and name usage guidelines

- Don't alter, recolor, distort, or combine the logo with other marks.
- Write the name as "KubeAstra" (capital K, capital A, one word).
- Don't use the Marks more prominently than your own product's name.

## Questions

If you're unsure whether your use is allowed, just ask — open an issue at
<https://github.com/astraverse-io/KubeAstra/issues> or contact the
maintainers. We're an open-source project; we want the name used, talked
about, and packaged — we only step in when usage would confuse people about
what is and isn't the official KubeAstra.
