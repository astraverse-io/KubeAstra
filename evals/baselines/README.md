# DeepEval Baselines & Rotation Policy

This directory contains baseline reports generated by the agent evaluation suite. These files are used in CI/CD runs to prevent regressions in reasoning, tool usage, safety constraints, and answer synthesis.

## Main Files

- **`current.json`**: The comparison anchor for CI/CD runs. Every Pull Request and nightly run evaluates the latest agent code and compares its results against this file.
- **`<YYYY-MM-DD>-stage1-*.json`**: Dated snapshots of prior runs. These are immutable archives capturing quality metrics at specific points in time.

## Baseline Rotation Policy

To promote a new run as the baseline comparison anchor:

1. **Perform an Evaluation**: Run the evaluation suite on the backend target:
   ```bash
   python ui/backend/scripts/eval_agent_deepeval.py \
     --backend-url http://localhost:8000 \
     --output evals/baselines/$(date +%F)-new-baseline.json
   ```
2. **Review and Verify**: Check the summary output and the report to ensure the new run is accurate and shows improved or expected results.
3. **Copy to current.json**: Overwrite `current.json` with the new baseline file:
   ```bash
   cp evals/baselines/$(date +%F)-new-baseline.json evals/baselines/current.json
   ```
4. **Create a Pull Request**: Submit the updated `current.json` in a pull request. The PR description **MUST** include a justification block detailing:
   - What improvements were introduced.
   - Scenario-by-scenario metrics changes.
   - The reason for updating the baseline.
