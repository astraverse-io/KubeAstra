# Python 3.11+ required

# app. Deliberately excludes two things:
#
#   * torch + sentence-transformers — local embeddings. Installed ~770MB with
#     their transitive deps (scipy, sympy, sklearn, transformers), which is
#     acceptable in a container and impossible in a desktop installer. Desktop
#     computes embeddings through the provider's API instead
#     (EMBEDDINGS_MODE=api) or a local Ollama daemon.
#   * test and type-checking tooling — not needed at runtime.
#
# Both live in requirements.txt, which includes this file.

# so no separate dependency is needed there.
